3 rules, or the code breaks

  1. Same names. Rename every sprite, costume and backdrop exactly as written here, with the same spaces and capital letters.
  2. Same order. Some code picks a costume by its number (for example the scale, the meters, the calendar and the sick animals). Keep the costumes in the order shown.
  3. Transparent background for every sprite (PNG). Backdrops fill the whole stage: 480 x 360.

Words and numbers: type them in Scratch

AI images often misspell words. For titles, buttons, labels, prices and numbers, make the picture with no words, then add the words in the Scratch paint editor with the Text tool.

For numbered sets (scale, meters, bars, tickets, calendar), make costume 1, then duplicate it and change only the number.
